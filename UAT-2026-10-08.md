## Perubahan Baru

| Bagian | Implementasi |
| --- | --- |
| Homepage | Tombol hero menjadi Shop Flowers. Teks italic tetap Celebrate with Fresh Blooms tanpa Today; heading utama tidak diubah. |
| Promo | Promo diaktifkan pada database lokal. Tujuan promo lokal dan default kode menuju /shop?filter=sale. Pengaturan hosting tidak diubah. |
| Delivery / Cart | Field alamat lengkap multiline dipakai bersama pada produk dan cart. Draft alamat diteruskan ke cart; server menolak delivery tanpa alamat lengkap. |
| Occasion | Warna judul disamakan ke token ink. Selector CSS judul/harga kartu diperbaiki supaya menjangkau komponen ProductCard. Heading showcase tidak sticky. |
| Product | Foto dapat diperbesar 2x saat pointer bergerak di atas foto desktop; titik fokus mengikuti pointer. Panah dan progress tetap berfungsi, tanpa zoom pada perangkat touch. Progress foto mendukung Enter/Space. |
| About | Selector ikon diperbaiki; jarak ikon ke teks benar-benar 40px, bukan hanya deklarasi CSS yang tidak diterapkan. |
| CMS Produk | Input diskon 0-99%, validasi server, dan penyimpanan bersama perubahan produk dalam transaksi. Data diskon menggunakan tabel site_settings yang sudah ada. |
| Sale | Filter Sale terhubung ke diskon CMS, dengan badge dan harga normal dicoret. Harga diskon digunakan oleh catalog, pricing, dan checkout server. |
| Cart Pricing | Harga cart diambil dari /api/pricing, bukan snapshot lama. Checkout menunggu harga server selesai dimuat. |
| CMS Media | Upload langsung 1-10 foto JPG/PNG/WebP, preview, tombol ubah urutan dan hapus dari carousel. Maksimal 12 MB per foto; optimasi JPEG hingga 2400 px. |
| CMS Video | Upload langsung MP4/WebM hingga 100 MB, preview player, ganti atau hapus video About. About menjadi SSR agar perubahan media tampil tanpa rebuild. |

Media lama tetap dipertahankan. Upload baru disimpan di UPLOADS_DIR dengan nama unik; klik Simpan media untuk menerapkan perubahan. Menghapus dari daftar tidak menghapus file fisik, agar referensi lama tidak rusak. Embed YouTube tidak digunakan.

## Verifikasi

- Build produksi berhasil. Astro check: 0 errors, 0 warnings, 10 hint lama.
- Unit test validasi diskon, harga sale, dan URL media: 3 lulus.
- API lokal: guard admin, simpan/baca media, render carousel/video, diskon invalid, harga diskon, filter Sale, dan alamat wajib lulus.
- Data diskon/media yang diubah untuk tes dikembalikan ke kondisi awal. Promo lokal sengaja tetap aktif sesuai permintaan.
- Tidak membuat order atau invoice, mengirim email, atau mengirim WhatsApp.
- Browser: hero dan cart tanpa horizontal overflow; hero diuji pada lebar 320, 390, 1440, dan 2560px. Lebar hero maksimal 2000px.
- Browser: tiga foto galeri produk berhasil dimuat; Next berfungsi; Pickup menyembunyikan alamat.
- Browser: filter Graduation/Sale mengubah judul; panel berawal tepat di bawah navbar dan berakhir di bawah viewport.
- Browser: tinggi kolase About 700px, jarak ikon 40px, validasi Contact menonaktifkan/mengaktifkan submit sesuai field.
- Zoom hover telah diimplementasikan; gerakan pointer belum diuji otomatis karena API browser tidak menyediakan hover/move.
- Upload video, simpan/render, HEAD, partial byte-range 206 dan invalid range 416 diuji pada server hasil build lokal. Fixture menguji transport, bukan decoding. Playback video nyata belum diuji karena file video belum diberikan.
- Upload foto, preview, reorder, simpan dan reload diuji lewat browser CMS lokal. Konten asli dikembalikan sesudah tes.
